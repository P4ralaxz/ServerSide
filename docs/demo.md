ตั้งเครื่องไม่ให้หลับ เสียบสายชาร์จ แล้วรันทีละบรรทัด (PowerShell ใช้ `npm.cmd` แทน `npm`):


เปิดอีกหน้าต่างแล้วเปิด tunnel:


- `.env` ต้องตั้ง `APP_BASE_URL=https://tapestry-prone-washbowl.ngrok-free.dev` และ `TRUST_PROXY=true`
- `npm run seed` **ล้างข้อมูลทั้งหมด** — ซ้อมเสร็จแล้วต้อง seed ใหม่ก่อนเริ่มจริง (ขั้น 10 กดได้ครั้งเดียวต่อการ seed)
- ลองเปิด `https://tapestry-prone-washbowl.ngrok-free.dev/app` จากมือถือที่ใช้เน็ตมือถือ ให้เปิดได้ก่อนเริ่ม

### 0.4 เปิดแท็บและ login ไว้ก่อน

แต่ละแท็บ login ได้คนละบัญชีในเบราว์เซอร์เดียว (session แยกต่อแท็บ อยู่ได้ 8 ชม.)
แท็บมือถือ: กด `F12` → `Ctrl+Shift+M` → เลือกความกว้าง 360

| แท็บ | เปิดที่ | login ด้วย | จอ |
|---|---|---|---|
| A | `…/app` | **ยังไม่ login** — login สดในขั้น 2 | มือถือ |
| B | `…/app` | `+student2` | มือถือ |
| C | `…/app` | `+student3` | มือถือ |
| D | `…/app` | `+staff1` | เดสก์ท็อป |
| E | `…/app` | `+tech1` | มือถือ |
| H | `…/docs` | `+admin1` (ทำตามด้านล่าง) | เดสก์ท็อป |
| I | กล่องเมลของคนคุมจอ | – | เดสก์ท็อป |

วิธี login ในแท็บ B–E: ใส่อีเมล → **ส่งรหัสทางอีเมล** → เปิดรหัสในแท็บ I → ใส่รหัส 6 หลัก → **ยืนยันรหัส**

วิธีเตรียม Swagger (แท็บ H) ด้วย `+admin1`:
1. เปิด `POST /auth/request-code` → **Try it out** → body `{"email": "67070017+admin1@kmitl.ac.th"}` → **Execute**
2. เปิดรหัสในแท็บ I
3. เปิด `POST /auth/verify-code` → **Try it out** → body `{"email": "67070017+admin1@kmitl.ac.th", "code": "รหัส 6 หลัก"}` → **Execute**
4. คัดลอกค่า `access_token` จากผลลัพธ์ → กดปุ่ม **Authorize** ด้านบน → วาง → **Authorize** → **Close**

ขอรหัสอีเมลเดิมซ้ำได้ทุก 60 วินาที

3. **ซ่อมเสร็จ** → บันทึก `ล้างถาดน้ำทิ้งและท่อน้ำทิ้งตัน` → **ยืนยันซ่อมเสร็จ**

### 6. ผู้แจ้งกด "ยังไม่หาย" — แท็บ A

1. กดแท็บล่าง **ส่งซ่อมแล้ว** → กลุ่ม **รอคุณยืนยัน** → คลิกใบแอร์
2. **ยังไม่หาย** → กดส่งโดยไม่กรอก → โดนบล็อก
3. กรอก `เปิดไปสองชั่วโมงน้ำหยดอีก` → **ส่งกลับให้ช่าง**

พูด: ใบกลับไปหาช่างคนเดิมพร้อมเหตุผล ไม่ต้องเริ่มแจ้งใหม่

### 7. ช่างซ่อมรอบสอง — แท็บ E ⏱

1. **งานของฉัน** → refresh → ใบแอร์อยู่กลุ่ม **ถูกส่งกลับ** บนสุด พร้อมเหตุผลของผู้พัก
2. คลิกใบ → **เริ่มงาน** → **ซ่อมเสร็จ** → `เปลี่ยนท่อน้ำทิ้งเส้นใหม่` → **ยืนยันซ่อมเสร็จ**

### 8. Staff ยืนยันแทนไม่ได้ → รูมเมทปิดใบ — แท็บ D, B

1. แท็บ D: refresh → คลิกใบแอร์ → เห็น "Staff ยืนยันใบห้องพักแทนไม่ได้" — ไม่มีปุ่มยืนยัน
2. แท็บ B (รูมเมท ไม่ใช่คนแจ้ง): **ส่งซ่อมแล้ว** → คลิกใบแอร์ → **หายแล้ว ปิดใบ** → **ยืนยัน ปิดใบ**

พูด: สิทธิ์ยืนยันผูกกับห้อง ไม่ใช่กับคนแจ้ง · ใบส่วนกลางเท่านั้นที่ Staff ยืนยัน

### 9. รออะไหล่ + ความเห็นภายใน — แท็บ E, A

พูด: รออะไหล่ต้องบอกว่ารออะไร และรายงานไม่นับช่วงนี้เป็นเวลาซ่อม · ช่างกับ Staff คุยเรื่องราคาได้โดยผู้พักไม่เห็น
